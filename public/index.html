Hybrid Voice
On-device: checking… Online

Talk. It answers where it makes sense.

Short questions are answered on this device by Gemini Nano. Long, complex, or unsupported requests go to Gemini in the cloud. Every answer carries a badge telling you which one spoke.

Hold the mic (or hold Space) and speak.

Speech-to-text uses Chrome's Web Speech API, so voice input needs a connection; typed input works offline.

System status

On-device inference needs Chrome 139+ on desktop with the Prompt API enabled (chrome://flags/#prompt-api-for-gemini-nano-multimodal-input).
